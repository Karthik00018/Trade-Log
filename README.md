📊 Trade Log

Trade Log is an Android application designed to help users record, manage, and track their trading activities in one place. The application provides an organized way to maintain trade records and monitor trading performance.

🚀 Features
📝 Add and record trades
📈 Track profit and loss
📋 View trade history
🗂️ Manage trading records
📊 Monitor trading activity
📱 Simple and user-friendly Android interface
🛠️ Technologies Used
Android
Kotlin
Android Studio
Gradle

⚙️ Getting Started
Prerequisites
Android Studio
Android SDK
JDK
Installation
Clone the repository:
git clone https://github.com/Karthik00018/Trade-Log.git
Open the project in Android Studio.
Allow Gradle to sync and download the required dependencies.
Connect an Android device or start an Android Emulator.
Build and run the application.
🎯 Purpose

The project was developed as an Android development project to create a practical application for maintaining and monitoring trading records while gaining hands-on experience in mobile application development.
